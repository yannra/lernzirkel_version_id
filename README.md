# Lernzirkel version

One file, `version.json`, saying when the revision agent for LCOMP72119 was last built and which
blocks changed. A student's copy reads it at startup and, if a newer build exists, says that a new
version is on Canvas.

It holds no course material: a version, a date, a commit id, and one digest per block. The course
itself is distributed through Canvas only.
